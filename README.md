# gb-ai

Research repository for a case study on integrating **Agentic AI** into [GoodBarber](https://www.goodbarber.com), a No-Code App Builder platform, so that users can create native applications by **describing** them in natural language instead of assembling them manually.

## Context

GoodBarber lets users build native apps from scratch by selecting and configuring sections, layouts, and extensions. This project explores how agentic AI tools could be layered on top of that existing platform — its JSON-based application structure, component library, and extension ecosystem — without replacing it with a parallel, disconnected system.

The work is structured in four stages:

1. Understand the GoodBarber platform.
2. Build a reference app using the platform.
3. Case study: how Agentic AI could be integrated to enable description-driven app creation.
4. Implement a prototype/solution.
