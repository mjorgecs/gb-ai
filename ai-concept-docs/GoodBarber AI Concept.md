
# Introduction

In the past few years, the vast majority of the No-Code App Builder platforms have been adopted AI tools to get to the next stage of the No-Code industry: building by **describing** your idea.

This new approach succeeds the manual-assembly model, where people had to assembly the app using a visual interface that enabled to select pre-made components. Now, the AI tools can create new apps from scratch and write custom components for existing apps, which leads to more personalized apps.
