# Description

This section of the report addresses the objectives and the expected milestones of this internship project. 

As explained in the introduction, the GoodBarber's platform must improve (?) its building process by allowing users to create a new app by describing it to an AI agent that creates it and gives it to the user to custom or refine it. With that in mind, it is essential to study and do some research about:
- The already available solutions.
- The approaches that can be taken to implement AI agent.
- The feasibility of the project and others trade-offs.

The work developed during this internship must address all these topics and, at the end of the internship, develop a proof of concept that embodies the work developed during the internship.

This work can be divided into three different stages: **Research**, **Documentation**, **Implementation**. The last two stages can performed continuously to guarantee the accuracy of the final product and its documentation 

#  1. Research

1. State of the art: draw a picture about the No-Code App Builder platforms available in the market.
2. Agentic AI: how to use AI agents to perform repetitive tasks, and and complex ones like interpret the information provided by users to build apps.
3. How the GoodBarber's platform works: test the GoodBarber's platform by creating an application and explore it.
4. The platform's codebase: analyze the platform's codebase to extract more information about its structure and configurations. 
# 2. Documentation

1. Problem definition: set the motivation to do this project.
2. Possible solutions: define the best solution in this case and compare it with the ones available in the market.
3. Challenges: compare the advantages and disadvantages of each solution.

# 3. Implementation

Develop a PoC (Proof of Concept) that aggregates all the work done in the two previous stages. This PoC will take the form of an AI agent that can extract application's characteristics from user's prompts and present them in a JSON object.
